# Enterprise API Gateway

A Java-based API Gateway that demonstrates **Token Bucket Rate Limiting**, **Asynchronous Request Processing**, and **Traffic Management** using Java Servlets, multithreading, and JDBC.

## Features

- Per-Tenant API Key Authentication
- Token Bucket Rate Limiting
- Asynchronous Request Processing
- Fixed Thread Pool using ExecutorService
- Bounded Queue (ArrayBlockingQueue)
- HikariCP Connection Pooling
- JDBC Transaction Management
- Interactive Dashboard for Request Simulation
- HTTP 202, 401, 429 & 503 Response Handling

---

## Tech Stack

- Java
- Jakarta Servlet
- Embedded Apache Tomcat
- JDBC
- HikariCP
- H2 Database
- HTML
- Tailwind CSS
- JavaScript
